## 这一章要回答的问题

> **一个几百 GB 甚至上 TB 的模型，怎么放到几千张卡上训出来？**

整章其实只在解决两个约束的对抗：**显存不够** 和 **通信太慢**。每一篇论文都是在二者之间找一个更好的平衡点。

## 先记住这张账

一个 $P$ 参数、用 Adam 训练的模型，FP16 混合精度下每张卡要放：

| 项目 | 字节数 | 说明 |
| --- | --- | --- |
| 参数（FP16） | 2P | |
| 梯度（FP16） | 2P | |
| 优化器状态（FP32 副本 + 动量 + 方差） | 12P | **最大的一块** |
| **合计** | **16P** | 不含激活值 |

所以一个 7B 模型仅模型状态就要 **112 GB**——一张 80 GB 的卡都放不下。这就是 ZeRO 存在的理由。
